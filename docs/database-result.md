# Database Result

`DatabaseResult` is returned by database operations such as `Database:query()` and `Database:exec()`.

It represents the result of a SQL operation and provides access to rows, columns, affected rows, and insert IDs.

## Getting a Result

```lua
local db = Drogua.Database.get("default")

local result = db:query([[
    SELECT id, name
    FROM users
    ORDER BY id
]])

print(result:count())
print(result:columns())
```

## Rows and Columns

Use `count()` or `size()` to get the number of rows.

Use `columns()` to get the number of columns and `columnName()` to get a column's name.

```lua
local result = db:query([[
    SELECT id, name
    FROM users
]])

print(result:count())          -- number of rows
print(result:size())           -- same as count()
print(result:columns())        -- number of columns

print(result:columnName(0))    -- "id"
print(result:columnName(1))    -- "name"
```

Column indexes are **zero-based**.

## Accessing Rows

Use `row(index)` to retrieve a `DatabaseRow`.

```lua
local result = db:query([[
    SELECT id, name
    FROM users
    ORDER BY id
]])

local first = result:row(0)
local second = result:row(1)

print(first:get("id"))
print(first:get("name"))

print(second:get("id"))
print(second:get("name"))
```

See **[Database Row](database-row.md)** for working with individual rows.

## Convert to a Lua Table

`toTable()` converts the entire result into a normal Lua table.

```lua
local result = db:query([[
    SELECT id, name
    FROM users
    ORDER BY id
]])

local users = result:toTable()

for i, user in ipairs(users) do
    print(user.id, user.name)
end
```

The resulting structure looks like:

```lua
{
    {
        id = "1",
        name = "Alice"
    },
    {
        id = "2",
        name = "Bob"
    }
}
```

> Database values are currently converted to strings by `toTable()`.

## Affected Rows

For `INSERT`, `UPDATE`, or `DELETE` operations, use `affectedRows()`.

```lua
local result = db:exec([[
    UPDATE users
    SET name = 'Alice Updated'
    WHERE id = 1
]])

print(result:affectedRows())
```

## Insert ID

Use `insertId()` to retrieve the ID generated by an insert.

```lua
local result = db:exec([[
    INSERT INTO users (name)
    VALUES ('Charlie')
]])

print(result:insertId())
```

## String Representation

`toString()` provides a short description of the result.

```lua
local result = db:query("SELECT * FROM users")

print(result:toString())

-- LuaResult(2 rows, 2 columns)
```

## API

| Method              | Description                         |
| ------------------- | ----------------------------------- |
| `size()`            | Number of rows                      |
| `count()`           | Number of rows                      |
| `columns()`         | Number of columns                   |
| `columnName(index)` | Get a column name                   |
| `row(index)`        | Get a `DatabaseRow`                 |
| `affectedRows()`    | Number of affected rows             |
| `insertId()`        | ID generated by the last insert     |
| `toTable()`         | Convert the result to a Lua table   |
| `toString()`        | String representation of the result |

**Note:** Database operations are currently synchronous, so these methods are safe to use from Drogua's synchronized routes.
